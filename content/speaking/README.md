# スピーキングテストのストック

「スピーキング」タブのテスト（TOEIC Speaking の写真描写と同じ形式：準備 45 秒・解答 30 秒）で使う問題です。

| ファイル | 中身 | 作り手 | git |
|---|---|---|---|
| `items.json` | 写真の取得元とクレジット（Unsplash）、模範解答、声、手本音声の単語・文の区間 | 写真の選定と模範解答：Claude | 管理する |
| `<ID>/photo.jpg` | 写真 | `trainer stock speaking`（URL から取得） | 管理外 |
| `<ID>/model_*.mp3` | 模範解答の音声（ElevenLabs・声はランダム） | `trainer stock speaking` | 管理外 |

- 写真は、人が何かをしている場面（オフィス、市場、駅、飲食店、工事現場、図書館、公園、港、教室、倉庫、空港、庭、路上演奏、カフェなど）から、要素が少なすぎるものや抽象的なものを除いて選びました
- 模範解答は TOEIC の解答例に合わせ、60〜80 語・現在進行形中心で「場所 → 中心の人や物 → 周り → 背景」の順に描写しています
- 写真と音声が無い場合は `uv run --project apps/trainer trainer stock speaking` で取り直せます（音声はクレジットを使います）
