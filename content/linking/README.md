# 発音：リンキングの例題

「発音」タブで使う、音のつながり（リンキング）の例題です。

| ファイル | 中身 | 作り手 | git |
|---|---|---|---|
| `items.json` | 型の説明、例題（フレーズ・聞こえ方・例文）、声、音声の区間 | 例題：Claude | 管理する |
| `<ID>/model_*.mp3` | フレーズと例文の音声（ElevenLabs・米国の声からランダム） | `trainer stock linking` | 管理外 |

- 型は 8 つ × 25 例：子音＋母音 / 母音＋母音 / 同じ子音が続く / t がラ行っぽくなる / 音が消える / 音が混ざって変わる / 弱く短くなる / h が消える
- `‿` は音がつながる所、`()` はほとんど聞こえない音。カタカナはアメリカ英語での聞こえ方の目安
- 生成した音声は Scribe で文字起こしして、読み間違いが無いことを確かめた
- 音声が無い場合は `uv run --project apps/trainer trainer stock linking` で作り直せます（クレジットを使います）
